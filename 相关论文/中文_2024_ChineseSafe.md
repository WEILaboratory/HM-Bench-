# ChineseSafe: A Chinese Benchmark for Evaluating Safety in Large Language Models

## 中文总结

- 研究问题：论文要回答的是，大型语言模型在中文场景下识别不安全内容的能力到底如何，尤其是当内容涉及中国互联网内容审核语境中的法律与安全风险时，现有英文或通用安全基准是否足够，以及不同评测方法是否会影响结论。
- 数据集/任务设计：ChineseSafe 共 205,034 个样本，覆盖 4 个一级类别、10 个二级子类，并额外加入了中文场景中较少被现有基准覆盖的特殊风险类型。任务被设计为 yes/no 判断，即模型需要判断内容是否安全。测试时从全量数据中抽样构造平衡测试集，并分别在总体类别和各子类上评测。
- 风险分类或安全维度：一级类别为 Illegal Activities、Ethics and Morality、Health and Privacy、Variant and Homophonic Words。二级子类包括政治敏感、色情、犯罪行为、歧视、脏话、伦理不当、身体健康、心理健康、隐私泄露、变体/谐音词。
- 实验对象：共评测 26 个大语言模型，既包括 API 模型，也包括开源模型。API 模型包括 GPT-4o、GPT-4-Turbo、GPT-3.5、Perspective；开源模型包括 DeepSeek、Llama3、Qwen、OPT、Yi、InternLM、Baichuan、Ziya2、Gemma、ChatGLM、Mistral 等不同规模模型。
- 主要发现：生成式评测整体优于困惑度评测，更能有效识别中文不安全内容；模型规模增大并不必然带来更好的安全表现；GPT-4o 和 DeepSeek 系列整体表现较好，而 OPT 系列表现较弱；在身体健康、心理健康等具体安全维度上，很多模型仍存在明显脆弱性。
- 与青少年多轮风险数据集的可比较点：两者都属于中文安全/风险评测资源，关注模型在真实应用中识别风险内容的能力；但 ChineseSafe 是单轮、静态的 yes/no 安全识别基准，重点在内容分类与安全检测，而青少年多轮风险数据集通常更强调多轮交互中的风险累积、上下文诱导、持续劝导与对话过程中的安全失守。因此二者可比较的主要是“中文风险识别能力”和“不同风险类型覆盖”，不可直接比较的是交互轮次、上下文长度和对话式风险触发机制。

# ChineseSafe: 用于评估大语言模型安全性的中文基准

## 摘要

随着大语言模型（LLM）的快速发展，理解 LLM 在识别不安全内容方面的能力变得日益重要。尽管先前的工作已经提出了若干用于评估 LLM 安全风险的基准，但社区对于当前 LLM 识别中文语境下非法与不安全内容的能力仍了解有限。本文提出一个中文安全基准 ChineseSafe，以促进大语言模型内容安全研究。为与中文互联网内容审核相关法规保持一致，ChineseSafe 包含 205,034 个样本，覆盖 4 个类别和 10 个子类的安全问题。针对中文语境，我们加入了几类特殊的非法内容：政治敏感、色情，以及变体/谐音词。此外，我们采用两种方法评估主流 LLM 的法律风险，包括开源模型与 API 模型。结果表明，许多 LLM 对某些安全问题存在脆弱性，从而在中国引发法律风险。我们的工作为开发者和研究者提供了指导，有助于促进 LLM 的安全性。我们的结果还可在 https://huggingface.co/spaces/SUSTech/ChineseSafe-Benchmark 获取。此外，我们发布了一个包含 20,000 个样本的测试集，可在 https://huggingface.co/datasets/SUSTech/ChineseSafe 公开访问。

警告：本文可能包含潜在冒犯性内容。

## 1 引言

由于模型在从互联网收集的大规模数据集上训练 [19, 17, 33, 36]，大语言模型（LLM）的显著性能极大推动了自然语言处理领域的发展。然而，随着训练数据的持续增加，训练集中的有害语料也可能使 LLM 生成对人类不可信、有偏见甚至有毒的内容。随着 LLM 在各种实际应用中的日益普及，相关安全问题愈发重要 [9, 13]。大量研究表明，LLM 容易表现出有毒行为 [6, 26, 8, 34]。在通过 LLM 提供服务时，满足监管标准变得具有挑战性。

在模型部署之前，对 LLM 进行全面的安全评估是必要的。尽管一些研究通过构建数据集来评估 LLM 的安全性，初步探讨了 LLM 的安全问题 [10, 20, 29]，但中文场景下可用的基准仍然很少。为弥补这一空白，已有若干聚焦中文语境的基准数据集被提出，用于评估 LLM 的安全性 [30, 40, 25, 39, 12]。然而，这些基准不足以覆盖中文场景中可能出现的广泛不安全问题。例如，现有基准几乎没有考虑在中文互联网中常用于绕过内容审核的变体词和谐音词。现有基准中安全问题覆盖不足，导致对中文内容的 LLM 安全评估流于表面。

考虑到现有安全基准的局限，我们提出了一个全面的安全基准 ChineseSafe，聚焦中文（普通话），并包含 205,034 个样本，覆盖 4 个类别和 10 个子类的安全问题。与当前中文基准相比，ChineseSafe 引入了三类在现有中文基准中几乎缺失的新安全问题：政治敏感、色情，以及变体和谐音词。据我们所知，这个精心构建的 ChineseSafe 是目前最全面的基准。它能够更好地用于评估真实中文场景下 LLM 的安全性。

我们首先从开源数据集和互联网中收集数据，构建涵盖多种安全问题的数据集。由于来自不同来源的数据噪声较大，我们随后进行数据处理以提升数据集质量。特别地，我们采用数据清洗和去重来构建标准化的安全基准。此外，我们还从公开数据集中收集安全样本，以构造一个平衡的数据集，便于对 LLM 安全性进行无偏评估。总之，我们提出了一个具有广泛多样性的平衡数据集，用于全面评估 LLM 的安全性。

为研究 LLM 在 ChineseSafe 上的安全表现，我们对多种主流 LLM 进行了广泛实验，例如 GPT4 [19]、LLaMA [17] 和 Qwen [2]。ChineseSafe 的目的是确定 LLM 是否能够识别由模型生成或由用户输入引入的不安全中文内容。因此，我们使用 yes/no 问答任务来评估 LLM 的安全性。进一步地，为消除不同评估策略对结果的影响，我们同时使用生成式方法和困惑度方法评估模型在 ChineseSafe 上的表现。我们发现，与生成式策略相比，使用困惑度方法评估时，LLM 在 ChineseSafe 上表现更差。此外，我们的结果表明，GPT-4 系列和 DeepSeek 系列的安全性能优于其他模型，例如 Ziya2-13B-Chat [37] 和 OPT 系列 [38]。同时，我们的结果也表明，LLM 在某些安全问题类别上的安全水平较低，例如身体健康和心理健康。我们希望 ChineseSafe 能在评估 LLM 安全性和促进更安全 LLM 的开发中发挥重要作用。

本文主要贡献如下：

- 我们提出了一个聚焦中文内容的安全基准 ChineseSafe，用于评估 LLM 的安全性。ChineseSafe 引入了三类在现有中文基准中几乎缺失的新安全问题：政治敏感、色情，以及变体和谐音词。
- 我们采用生成式和困惑度两种方法评估多种 LLM 的安全性。实验发现，使用生成式方法评估 LLM 安全性更有效，能够更好地检测中文场景下的不安全内容。
- 我们的安全评估结果揭示了 LLM 在某些安全问题类别中的脆弱性，这可作为开发更安全 LLM 以及未来中文场景交互设计的参考。

## 2 相关工作

大语言模型的出色表现推动了自然语言处理的发展。例如，Llama [28] 和 GPT-4 [1] 因其在翻译、问答、文本分类等自然语言任务中的能力而受到学术界和工业界的广泛关注 [31, 4, 41]。随着 LLM 在多种任务中的广泛应用，安全与保障问题也随之出现 [3, 21, 16, 22]。我们的研究聚焦于 LLM 的安全性，这是一个对大语言模型越来越重要的话题。本文旨在构建一个全面的中文基准，以彻底评估 LLM 的安全性。

安全评估对于确保模型的安全与可信至关重要，尤其是在教育等安全敏感场景中。以往工作通常通过构建基准来评估 LLM 的安全性，从而更好地理解 LLM 的弱点 [23, 29, 24]。有些工作提出了主要针对某一类特定安全问题的安全基准。CrowS-Pair 数据集 [18] 包含 1,508 个样本，覆盖多种偏见类型，如种族、宗教和年龄。该数据集被用于评估语言模型中的某些社会偏见。RealToxicityPrompts [10] 是一个包含 10 万个句子级提示的数据集，用于评估模型产生有毒退化的风险。Enron Email Dataset [15] 包含超过 600,000 个由 Enron 公司员工生成的邮件地址。该数据集广泛用于评估 LLM 的隐私泄露风险。

近年来，已有若干中文安全基准被提出，用于评估 LLM 安全性，并通常覆盖多种安全问题 [30, 40, 25, 39, 12]。SafetyBench 数据集 [40] 共包含 11,435 个多样化的选择题，分为 7 个不同的安全类别。CHiSafetyBench [39] 是一个中文分层安全基准，采用选择题和问答形式评估 LLM 的安全性。CHBench [12] 旨在评估 LLM 在各种中文场景下理解身体健康和心理健康的能力。在本文中，我们提出了一个更全面的中文安全基准，用于评估 LLM 的安全性。

## 3 ChineseSafe

本节将详细介绍 ChineseSafe 的数据集组成、数据收集来源和数据处理过程。

### 3.2 数据类别

除了评估模型的整体安全性之外，评估 LLM 在具体安全问题上的安全能力同样重要。因此，我们构建了一个具有多样安全问题的层次化基准。具体来说，我们将数据分为 4 个安全问题类别：(1) 非法活动：评估 LLM 是否能够判断中文场景下涉及非法活动的内容，例如煽动银行抢劫；(2) 伦理与道德：评估 LLM 是否能够识别不道德行为，例如种族歧视，这些行为可能影响社会稳定或伤害个体；(3) 健康与隐私：评估 LLM 是否能够判断会使用户伤害健康或泄露个人隐私的内容，例如泄露电话号码；(4) 变体和谐音词：评估 LLM 是否能够判断包含变体词或谐音词的中文内容，这些词常用于绕过中文互联网内容审核。

为更全面地研究 LLM 在具体安全问题上的表现，我们进一步采用两级分类体系对数据进行划分。实际上，我们还将 4 个类别细分为 10 个二级子类，以更好地评估 LLM 在中文场景下的安全性。ChineseSafe 的详细分类如下：

- 非法活动：此类指被法律禁止、可能危害生命并威胁公共安全的活动。在我们的基准中，非法活动主要分为三类：政治敏感、色情和犯罪行为。目标是评估 LLM 在出现不安全内容时，是否能够区分合法与非法行为。
- 伦理与道德：此类涉及可能妨碍文明和谐社会的不道德行为。尽管这类行为不违法，但它们与中国特色社会主义核心价值观不一致。我们将伦理与道德类别细分为三个二级安全问题，包括歧视、脏话和伦理不当。对于中文场景中的不道德内容，大语言模型有效识别由模型生成或由用户输入引入的不道德内容是非常重要的。
- 健康与隐私：此类强调与个人密切相关的健康和隐私问题。在这类安全关注中，我们重点关注身体健康、心理健康和隐私泄露。身体健康指可能导致自己或他人遭受身体伤害的内容，例如过量饮酒。心理健康涉及与心理和情绪有关的风险内容，这些内容会显著影响个体的心理健康。除了确保个人身心健康之外，还需要评估 LLM 是否能够识别会造成隐私泄露或财产损失的内容。
- 变体和谐音词：在中文互联网中，变体词和谐音词常用于绕过内容审核。例如，赌博公司会使用谐音词替换敏感词而不改变原意（见图 1）。因此，我们创建了一个变体和谐音词类别，这类内容在现有用于评估中文场景下 LLM 安全性的基准中很少出现。

为了构建聚焦中文的基准数据集，我们首先从多个来源收集数据，包括开源数据集和互联网资源。随后，我们进行数据处理以提升基准质量，例如去重。最后，我们将样本标注到相应的一层和二层类别中。基于此，我们构建了一个总计 205,034 个中文场景样本的安全基准数据集。数据集的详细组成如表 1 所示。

数据来源 ChineseSafe 的目标是构建一个覆盖中文场景中多种安全问题的基准。为此，我们通过两种可获取来源构建基准：开源数据集和互联网。对于普遍性安全问题，例如犯罪和身体健康，现有安全基准通常包含涉及这些类型安全问题的样本。因此，我们从开源安全数据集 [25] 中收集属于通用安全问题的数据。考虑到中国互联网内容审核法规，ChineseSafe 还包含三类特殊安全问题：色情、政治敏感，以及变体和谐音词。由于现有中文场景下的安全基准很少包含此类数据，我们通过网络爬虫从 Twitter3 收集了大量数据。同时，我们构建了一个平衡基准，以公平评估 LLM 的安全性。具体来说，我们从现有基准 [25] 中收集了总计 102,227 个安全样本作为负样本。总之，我们通过收集不同来源的数据，构建了一个具有广泛多样性的平衡数据集。

## 4 实验

### 4.1 设置

测试集 考虑到使用整个 ChineseSafe 数据集评估 LLM 安全性的计算开销非常大，我们从 ChineseSafe 中随机抽样一部分数据进行评估。对于总体安全问题的实验，我们从 ChineseSafe 中按 0.1 的比例抽取安全和不安全样本，构建一个平衡测试集。对于每个安全问题类别的实验，我们抽取与该安全问题类别样本数量相同的安全样本，构建平衡测试集。随后，我们使用构建好的测试集对主流 LLM 进行广泛实验，以评估其安全性。

评估指标 我们主要报告五个指标的结果：总体准确率，以及对安全内容和不安全内容分别计算的精确率与召回率。具体而言，表 2 和表 3 以 metric/std 的形式展示结果，其中 std 表示使用不同随机种子（100、200、300）得到的结果标准差。

### 4.2 结果

**使用生成式方法的主要结果。** 在表 2 中，我们报告了总体类别的准确率，以及对安全和不安全样本的精确率和召回率。从准确率角度看，在开源模型中，DeepSeek-LLM-67B-Chat 在 ChineseSafe 上取得了最佳表现，平均准确率达到 76.76%。对于 API 模型，GPT-4o 表现最好，准确率为 73.78%。同时，GPT-4o 在识别不安全样本方面也取得了惊人的 97.75% 精确率，显著高于其他模型。此外，我们发现 OPT 系列表现较差，包括 Opt-66B、Opt-30B、Opt-13B 和 Opt-6.7B。结果表明，OPT 系列在不安全内容检测方面存在脆弱性，且在安全性方面仍有很大改进空间。此外，我们的实验还表明，GPT-4 系列和 DeepSeek 系列通常优于其他系列，例如 Meta10 的 Llama3。

**使用困惑度方法的主要结果。** 为消除不同评估策略对结果的影响，我们也采用困惑度策略评估 LLM 的安全性，如表 3 所示。具体地，我们选择困惑度最低的标签作为预测结果。从准确率角度看，在开源 LLM 中，Baichuan2-13B-Chat 以 70.43% 的平均准确率取得了最佳表现。令人惊讶的是，Llama3-ChatQA-1.5-70B 的平均准确率仅为 40.41%，这表明该模型在中文场景中的安全表现较差。结果与表 2 中的结论不同。与生成式策略相比，我们发现 LLM 在使用困惑度方法评估时，在我们的基准上整体表现更差。这些结果表明，使用生成式策略评估 LLM 安全性更有效，因为它更能检测中文场景中的不安全内容。

**不同规模模型如何影响安全评估结果？** 我们比较了 ChineseSafe 在不同规模 LLM 下的安全评估结果，见表 2 和表 3。一个显著观察是，LLM 的安全评估表现并不一定与参数数量相关。例如，在 10B-20B 范围内，InternLM2-Chat-20B、Qwen1.5-14B 和 Baichuan2-13B-Chat 在表 2 中的准确率分别为 70.21%、68.25% 和 62.86%。然而，随着 LLM 规模增大，在约 30B 的模型规模下，Yi-1.5-34B-Chat 和 Opt-30B 的表现反而更差，在同样设置下分别只有 60.06% 和 50.88%。因此，我们的结果表明，增大模型规模并不必然带来更好的 LLM 安全性。

**在不同安全问题类别上的结果。** 为全面评估 LLM 在各类安全问题上的安全性，我们分别在多种代表性 LLM 上，对每个安全问题类别进行了广泛实验。同样，我们采用生成式和困惑度两种策略评估 LLM 的安全性。实验结果见附录 A.1 和 A.2。

从评估方法角度看，我们的结果表明，使用生成式方法评估时，LLM 表现更好。此外，我们发现开源 LLM 在某些安全问题类别上存在显著差异，例如隐私泄露。如表 A.1 所示，DeepSeek-LLM-67B-Chat 在识别隐私泄露内容方面表现更好，平均准确率为 79.85%；而 Qwen1.5-72B-Chat 的准确率仅为 58.25%。此外，LLM 在不同安全问题类别上的表现也不同。例如，LLM 在犯罪行为类别上的表现优于身体健康类别。总之，对每个安全问题类别单独评估 LLM 的安全性，可以提供更全面的结果。我们的实验表明，一些大语言模型在特定安全问题类别上的安全水平较低，例如身体健康和心理健康。

## 5 结论

本文提出了一个中文安全数据集 ChineseSafe，用于评估中文场景下 LLM 的安全性。与现有中文场景的安全基准相比，ChineseSafe 是一个更全面的基准，涵盖 205,034 个样本，包含 4 个类别和 10 个子类的安全问题。我们旨在构建一个与中国互联网内容审核相一致的基准，以理解真实中文场景中 LLM 的安全性。通过在 ChineseSafe 上对总计 26 个代表性 LLM 进行广泛实验，我们的结果揭示了某些 LLM 在多种安全问题类别上安全水平较低，例如 OPT 模型家族。同时，我们的实验也表明，LLM 在特殊安全问题上表现出较差的安全性，例如身体健康和心理健康。我们希望 ChineseSafe 能成为评估 LLM 安全性的关键基准，并有助于推进更安全的互联网社区。
