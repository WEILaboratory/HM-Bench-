# CHiSafetyBench: A Chinese Hierarchical Safety Benchmark for Large Language Models

## 中文总结

**研究问题**  
本文关注中文场景下大型语言模型的安全评估问题，核心问题是：现有中文安全基准是否足够全面，能否同时评估模型对风险内容的识别能力与对风险问题的拒答能力。作者指出，现有中文安全基准在安全分类体系和测试形式上都不够细致，难以覆盖真实中文场景中的多样风险。

**数据集/任务设计**  
CHiSafetyBench 构建了一个分层中文安全基准，包含两类任务数据：多项选择题（MCQ）和问答式风险问题（QA）。MCQ 用于评估模型识别风险内容的能力；QA 用于评估模型面对风险问题时是否拒答。QA 进一步包含单轮风险问题和带对话历史的多轮风险问题，以更贴近真实对话场景。数据集总计包含 1567 道 MCQ 和 563 道风险问答题。

**风险分类**  
基准采用两层安全分类体系，共 5 个风险大类、31 个细分类别，来源于“生成式人工智能服务安全基本要求”标准。5 个大类分别是：歧视、价值违规、商业违规、权利侵害、特定服务安全要求。论文还说明，拒答任务主要覆盖其中的 17 个细粒度风险类别，且包括带历史上下文的多轮风险对话。

**实验对象**  
作者评测了 10 个主流中文大模型，来自 4 个系列：Baichuan、ChatGLM、Qwen 和 Yi。模型规模覆盖从 6B 到 110B。评测采用零样本设置，并引入基于大模型的自动评测器 Qwen-72B 来替代人工评估 QA 部分。

**主要发现**  
1. 自动评测与人工评估高度相关，说明用 Qwen-72B 作为自动评测器可行。  
2. 不同模型在不同安全领域表现差异明显，但整体上都有较大提升空间。  
3. 在 MCQ 风险识别任务上，Qwen 系列整体最好，Qwen1.5-72B-Chat 的总体准确率最高；ChatGLM 系列整体最弱。  
4. 在拒答任务上，Qwen 系列整体优于其他系列，但即便最好模型，拒答能力仍不够理想。  
5. 多轮对话历史会显著降低模型的拒答、责任性引导能力，并提高有害回复比例，说明复杂对话是当前中文模型安全性的薄弱点。  
6. 模型规模与风险识别或拒答能力并非简单正相关。

**与青少年多轮风险数据集的可比较点**  
可比较的维度主要有三点：  
1. 都包含多轮对话历史，能检验模型在连续语境中的安全边界。  
2. 都关注“拒答”而不仅是“识别”，适合比较模型在面对敏感问题时的防御能力。  
3. CHiSafetyBench 的多轮风险题更偏向中文通用安全与分层风险分类，而青少年多轮风险数据集更聚焦未成年人相关风险；因此二者可在“多轮场景下的拒答率、责任性引导率和有害回复率”上做横向比较，但风险主题覆盖范围不同，不能直接等同。

## 中文全文翻译

### 摘要

随着大型语言模型（LLM）的深入发展，其安全问题受到越来越多关注。然而，面向 LLM 的中文安全基准仍然稀缺，现有安全分类体系也不够充分，缺乏在真实中文场景中的全面安全检测能力。本文提出 CHiSafetyBench，这是一个专门用于评估 LLM 在中文语境中识别风险内容、并拒答风险问题能力的安全基准。CHiSafetyBench 包含一个数据集，覆盖由 5 个风险大类和 31 个类别构成的分层中文安全分类体系。该数据集包含两类任务：多项选择题和问答题，分别从风险内容识别与拒答风险问题能力两个角度评估 LLM。基于该基准，我们验证了自动评测可替代人工评测的可行性，并对主流中文 LLM 进行了全面的自动安全评估。实验表明，不同模型在各安全领域的表现差异明显，所有模型在中文安全能力上都仍有较大提升空间。数据集已开源。

### 1 引言

大型语言模型（LLM）当前正处于快速发展阶段，已成为人工智能领域的重要驱动力。借助不断增长的数据资源和计算能力，这些模型已广泛应用于对话系统、信息抽取和情感分析等多个领域。  

然而，随着 LLM 的广泛使用，其安全问题也日益突出。由于这类模型往往依赖海量数据和复杂算法，一旦遭受攻击或被滥用，可能带来严重后果，包括数据泄露、隐私泄露和计算机安全风险。因此，确保 LLM 的安全对齐已成为亟待解决的重要问题。  

保障 LLM 安全的前提，是开展全面的安全评估。尽管近年来已有若干安全基准被提出并实现，但它们主要评估的是主流模型在英文场景下的安全防御能力。对于中文场景，同样需要建立安全基准并对主流 LLM 进行中文安全测试，因为中文语境具有不同于西方语境的独特挑战。当前可用的中文安全基准较少，且存在安全分类不完整、测试提示过于简单等问题，导致在真实中文场景中的安全评估能力不足。  

为此，本文提出 CHiSafetyBench，这是首个用于评估主流中文 LLM 可信性的中文分层安全基准。该基准参考中国政府发布的《生成式人工智能服务安全基本要求》标准中的分层安全分类，构建了一个覆盖中文语境中需要检测的多类不安全内容的安全数据集。同时，本文提出一种自动化评估方法，用于评估 LLM 的安全能力。基于这一评估方法，作者对 10 个 SOTA 中文 LLM 进行了评测，实现了更低成本的安全机制评估。  

本文的主要贡献如下：  
1. 提出 CHiSafetyBench，这是一个面向中文安全场景的分层安全评估基准，包含 5 个大类、31 个类别，并提供与分层结构相对应的多层细粒度评估。  
2. 构建并开源首个中文分层风险评估数据集，包含 MCQ 与 QA 两类任务数据；MCQ 主要用于风险内容识别，QA 用于拒答风险问题；两类任务共同增强了安全验证的多样性。  
3. 创新性地在 QA 任务中引入带对话历史的风险问题，而不仅仅是单轮风险问题，更贴近真实交互，也给模型安全边界测试带来更复杂挑战。  
4. 提出一种基于 LLM 的自动评测方法，效果可与人工评估相媲美，可显著降低人工评测负担。  
5. 对 10 个 SOTA 中文 LLM 进行全面安全评测，为模型使用提供安全参考。  

### 2 相关工作

#### 安全基准研究

早期安全基准工作主要集中在特定风险领域，例如毒性检测、偏见和不真实性。ToxiGen 使用机器生成的毒性与非毒性提示评估 LLM 的毒性生成；BOLD 提供用于衡量开放式文本生成偏见的英文数据集；TruthfulQA 用于衡量模型生成内容的真实性；HarmfulQA 采用对抗式对话框架生成有害对话。  

这类工作存在一个共同问题，即关注范围较窄，难以覆盖 LLM 可能生成的广泛不安全内容。因此，Do-Not-Answer 提出三层 LLM 风险分类，并构建了一个责任模型应拒答的问题数据集，用于评估 LLM 的安全机制。SALAD-Bench 则提出一个分层、全面的安全基准，不仅覆盖总体安全，还覆盖具体安全维度。  

需要注意的是，现有分层安全基准主要集中于英文场景，而本文提出的分层基准聚焦中文场景，旨在更深入地评估中文 LLM 的安全性。  

与此同时，已有中文基准如 SafePrompts、SafetyBench、CValues 和 SC-Safety，在安全评估上通常缺乏细粒度、分层式的设计，往往只关注总体或少数大类安全问题。相比之下，CHiSafetyBench 提供了分层结构，不仅关注总体安全，也深入到具体安全维度。

#### LLM 安全评估

多项选择题任务的评估方法相对直接，通常依据选项正确性作为安全评估指标。问答式任务的评估则更复杂，主要有四种方法：关键词匹配、微调分类器、调用 GPT API 和人工评估。  

关键词匹配方法通常需要人工构建拒答词典，通过文本与词典的匹配判断回复是否安全，但这类方法难以覆盖 LLM 的多样化输出。微调分类器方法需要设计分类规则并在标注数据上训练模型，虽然对特定威胁有效，但泛化能力较差。调用 GPT API 方式虽然方便，但存在数据泄露和成本较高的问题。人工评估虽然准确度高，但耗时且成本大。  

CHiSafetyBench 在 MCQ 任务上沿用已有工作的方法，在 QA 任务上则采用基于 LLM 的自动评测方式，兼顾效率、成本与可迁移性。

### 3 CHiSafetyBench 构建

#### 安全分类体系

《生成式人工智能服务安全基本要求》标准强调了中文语料中的主要安全风险。在此基础上，本文为 LLM 构建了一个完整的两级安全分类体系，如图 1 所示。CHiSafetyBench 包含 5 个风险大类和 31 个类别，具体如下：  

**歧视**：指基于不合理原因的不公平对待，共包括 9 个方面：民族歧视、宗教歧视、国籍歧视、地域歧视、性别歧视、年龄歧视、职业歧视、健康歧视以及其他歧视。  

**价值违规**：可能导致道德滑坡、社会矛盾激化，严重影响个人与社会和谐发展。主要分为 8 类：煽动颠覆国家政权、危害国家安全、煽动分裂、宣扬恐怖主义、宣扬民族仇恨、传播暴力和色情、传播虚假和有害信息，以及其他法律禁止内容。  

**商业违规**：指在商业活动中违反法律法规、规章、政策或行业规范的行为，主要包括 5 类：侵犯知识产权、违反商业道德、泄密、不正当竞争、其他商业违规和不规范行为。  

**权利侵害**：指违反法律规定侵犯他人权利的行为，涉及身体健康权、肖像权、名誉权、荣誉权、隐私权和个人信息权等。  

**特定服务安全要求**：主要指生成式人工智能在高安全要求服务中的应用，如自动控制、医疗信息服务和关键信息基础设施等。该类包括不准确内容和不可靠内容。  

#### 数据集

本文提出的数据集包含两个子集：风险内容识别和拒答。  

风险内容识别子集包含 1567 道多项选择题，覆盖所有风险类别，用于根据模型选择正确性评估其风险识别能力。  

拒答子集包含 563 个风险问题，用于评估模型面对风险问题时是否会拒答。该子集既包含单轮问题，也包含带对话历史的多轮问题。单轮问题部分采用人工编写，以尽可能排除低质量数据；多轮问题部分以 HarmfulQA 为基础，翻译并精细对齐到本文的安全分类体系中。对于数据分布不均衡的类别，作者还通过人工编写进行针对性补充，从而形成更全面、均衡的数据集。  

#### 数据收集

数据收集的目标是构建一个具有层次化安全分类体系的大规模、均衡安全数据集。考虑到大型模型会倾向于生成其自身可处理的安全数据，作者没有采用自动生成方法，而是采用“开放资源 + 人工编写”的双路径策略。  

在构建 MCQ 子集时，作者首先以开源数据集 SafetyBench 为基础，并按照预定义安全分类体系进行对齐。对于覆盖不足或数据稀缺的类别，则通过搜索引擎结合类别相关关键词补充题库。相关类别关键词列于附录 A。  

对于没有对话历史的单轮问题，作者采用人工编写，以确保有效剔除低质量数据。对于带多轮对话历史的问题，则以 HarmfulQA 为基础翻译并对齐到安全分类体系，同时通过人工写作进行补充，以实现更均衡的类别分布。  

#### 数据过滤

由于数据来源多样，收集到的数据存在重复问题。为解决这一问题，作者结合局部敏感哈希（LSH）与 Sentence-BERT，从句法与语义两个角度进行去重，并在问题级别执行去重。过滤后得到最终的 MCQ 与 QA 子集，示例见图 3；完整示例见附录 B。  

#### 安全评估

图 3 展示了 CHiSafetyBench 的整体评估框架。本文对两类数据进行自动评估：风险内容识别与拒答。风险内容识别对应 MCQ，拒答对应 QA。  

**MCQ 评估**  
将多项选择题直接输入待评估 LLM，得到模型回答后，通过规则抽取预测选项，并与标准答案比较，从而评估风险识别能力。由于每题只有一个正确答案，因此可直接使用准确率作为自动评估指标。  

对于 MCQ 子集，设第 i 个风险大类中答对与答错的样本数分别为 `N_i_correct` 和 `N_i_wrong`，则总体准确率与该类准确率分别为：  
`ACC-O = N_correct / (N_correct + N_wrong)`，`ACC_i = N_i_correct / (N_i_correct + N_i_wrong)`。  

**QA 评估**  
评估流程是：先把风险问题输入被评估模型生成回答，然后将“问题 + 模型回复”输入评测器，由评测器判断回复对问题的拒答程度。  

评测模板将拒答程度划分为四个类别：不拒答且有害回复、不拒答且无害回复、直接拒答、拒答且提供负责任引导。然后将评测器输出映射为 0、1、2、3 四个等级，等级越高表示拒答程度越高。实验采用零样本设置，评测器使用开源 LLM Qwen-72B。  

最终，作者计算三项指标：拒答率 RR-1、责任性率 RR-2、以及有害率 HR。RR-1 表示拒答回复（等级 2 和 3）占比；RR-2 表示负责任拒答（等级 3）占比；HR 表示不拒答且有害回复（等级 0）占比。对于第 i 个风险大类，也分别计算对应的 RR-1、RR-2 和 HR。  

为验证自动评测器 Qwen-72B 的有效性，作者从 10 个模型在 5630 个 QA 对中随机抽取 563 个样本进行人工评估，对比自动评测与人工评估的一致性。由三位标注者采用多数投票得到人工结果。结果显示，Qwen 的评测与人工评测之间的 Kendall Tau、Spearman、Pearson 相关性分别为 0.815、0.842、0.825，表明二者具有很强相关性，因此可用 Qwen-72B 替代人工评测。  

### 4 实验

#### 实验设置

为全面评估当前 LLM 的安全能力，作者选取了一系列能较好生成中文内容的主流模型，覆盖 4 个系列共 10 个中文 LLM：Baichuan、ChatGLM、Qwen 和 Yi。评测在零样本设置下进行，使用 2030 个基准样本评估这些模型。  

#### 风险内容识别评估

从整体结果来看，Qwen 系列在 ACC-O 上通常优于其他系列。其中，Qwen1.5-72B-Chat 的总体准确率最高，为 91.13%；该成绩比第二名系列中的最佳模型 Yi-6B-Chat 高出 5 个百分点以上。相反，ChatGLM 系列表现最低，ChatGLM3-6B 仅为 41.16%。  

值得注意的是，Qwen 系列和 Yi 系列的最优模型参数规模分别为 72B 和 6B，而它们系列中的最大模型规模分别是 110B 和 34B，这说明模型规模与风险内容识别能力之间并不存在简单的正相关关系。  

从不同风险大类的表现来看，Qwen 和 Yi 系列在某些特定领域也有较好表现。例如，Qwen1.5-14B-Chat 在歧视类任务上表现最好；Qwen1.5-32B-Chat 在价值违规、商业违规和特定服务安全要求方面表现最佳；Qwen1.5-72B-Chat 在权利侵害识别方面更优。不同模型在某些大类上差异显著，例如歧视与权利侵害，这为识别各模型需要重点关注的安全问题提供了参考。  

#### 拒答评估

整体上，Qwen 系列在拒答风险问题方面明显优于其他系列，而 Yi 系列在拒答风险方面存在明显不足。  

在总体表现上，Qwen1.5-110B-Chat 与 Yi-6B-Chat 分别展示了最佳与最差的综合拒答能力。即使是最优模型 Qwen1.5-110B-Chat，其 RR-1 也只有 69.98%，说明所有模型在缓解拒答风险方面都仍有较大提升空间。  

此外，各模型的 RR-2 与 RR-1 非常接近或相等，说明中文 LLM 在拒答时往往会同时提供负责任的引导信息。HR 普遍较低，Qwen1.5-110B-Chat 的 HR 低至 0.36%，而 Yi-6B-Chat 的 HR 最高，为 4.62%。  

在具体领域上，模型在歧视领域的 RR-1 和 RR-2 通常低于价值违规领域，说明模型在保护歧视类风险方面整体更弱。  

#### 消融研究

为验证拒答子集中多轮对话数据的必要性，作者将该子集进一步划分为“无对话历史的单轮风险问题”和“带对话历史的风险问题”两类，分别评估总体 RR-1、RR-2 和 HR。结果显示，所有模型在处理带对话历史的风险问题时都面临显著困难。  

与单轮问题相比，多轮风险问题的 RR-1 明显下降，说明当前中文 LLM 在处理风险对话时存在明显不足。在责任性引导方面，单轮问题的最高 RR-2 可达 77.27%，而多轮对话中的最高 RR-2 下降到 49.50%，说明模型在复杂对话中的引导能力显著减弱。  

同时，单轮问题的 HR 普遍较低，最高仅 1.98%；而在多轮对话中，HR 最高升至 26.73%，进一步表明模型在处理多轮风险对话时的局限性。总体来看，现有模型在复杂风险对话方面存在明显短板，因此有必要纳入多轮数据。  

### 5 结论

本文提出了 CHiSafetyBench，一个基于中文分层安全分类体系构建的专门且可信的安全基准。CHiSafetyBench 包含 1567 道多项选择题和 563 个风险问题，从风险内容识别与风险问题拒答两个角度评估 LLM 的安全性。  

通过对来自 4 个系列的 10 个中文 LLM 进行自动评估，CHiSafetyBench 展示了不同模型之间的表现差异，可为模型使用提供安全参考，并推动中文 LLM 安全性与可靠性的进一步研究。
