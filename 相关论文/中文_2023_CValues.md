# CVALUES: Measuring the Values of Chinese Large Language Models from Safety to Responsibility

## 中文总结

- 研究问题：本文关注中文大语言模型是否真正对齐了人类价值，尤其区分了两个递进层次的标准：基础层面的“安全”和更高层面的“责任”。作者想回答的不只是模型会不会输出有害内容，还包括它能否在社会、伦理、情感与公共利益层面给出更合适、更有担当的回应。
- 数据集/任务设计：论文提出了 CVALUES 评测基准。数据收集分为两类来源：一类是众包标注者构造的安全类 adversarial prompts，另一类是专业领域专家诱导出的责任类 prompts。随后又构造了 CVALUES-COMPARISON，用于自动评测的多选题数据集，包含正负响应对。评测同时采用人工评测与自动多选评测。
- 风险分类或安全维度：安全层面覆盖 10 个场景，包括危险话题、敏感话题、犯罪、身心健康、个人隐私、客观中立、伦理道德、恶意诱导、攻击指令和其他。责任层面覆盖 8 个领域，包括环境科学、心理学、数据科学、法律、社会科学、亲密关系、无障碍和冷门专业。
- 实验对象：人工评测中比较了 10 个中文 LLM，包括 ChatGPT、ChatGLM-6B、BELLE-7B-2M、ChatPLUG-3.7B、ChatPLUG-13B、MOSS、Chinese-LLaMA-13B、Chinese-Alpaca-Plus-7B、Chinese-Alpaca-Plus-13B、Ziya-LLaMA-13B。自动评测也使用了同一组模型中的若干模型，但排除了部分不适合多选任务的模型。
- 主要发现：多数经过指令微调的中文模型在“安全”上表现较好，但在“责任”上仍明显不足。自动多选评测与人工生成评测关注的侧重点不同，二者都重要，但不能互相替代。某些模型在多选题上看起来懂得区分安全与不安全，却在人工生成任务中仍会输出不够负责甚至有害的内容。模型规模增大并不必然带来更好的安全表现。
- 与青少年多轮风险数据集的可比较点：两者都属于面向风险识别与安全对齐的中文数据资源，都可以用于评估模型在高风险语境中的稳健性；都强调场景化风险分类和安全回复质量。不过，本论文的 CVALUES 主要是单轮 prompt 评测，并且进一步引入“责任”这一高阶维度，以及多选自动评测；如果与青少年多轮风险数据集比较，更适合对照“风险维度覆盖范围”“回复是否体现保护性引导”“是否依赖多轮上下文”这三点，而不是直接比较任务形式。

## 中文全文翻译

# CVALUES: 从安全到责任，衡量中文大语言模型的价值观

## 摘要

随着大语言模型（LLMs）的快速发展，人们越来越担心它们可能带来风险或产生负面的社会影响。因此，对人类价值对齐的评估变得愈发重要。以往工作主要关注 LLM 在某些知识和推理能力上的表现，而忽略了与人类价值的对齐，尤其是在中文语境下。本文提出 CVALUES，这是第一个中文人类价值评测基准，用于从安全和责任两个维度衡量 LLM 的对齐能力。为此，我们通过人工方式收集了跨 10 个场景的对抗性安全提示，并由专业专家在 8 个领域中诱导生成责任提示。为了全面评估中文 LLM 的价值观表现，我们不仅进行了可靠的人工评测，还构造了用于自动评测的多选提示。实验结果表明，虽然大多数中文 LLM 在安全性方面表现良好，但在责任性方面仍有很大提升空间。此外，自动评测和人工评测对于从不同方面评估人类价值对齐都很重要。基准和代码可在 ModelScope 和 GitHub 上获得。

## 1 引言

大语言模型（LLMs）已经展现出令人印象深刻的零样本和少样本泛化能力。为了评估 LLM 的进展，研究者提出了新的、更具挑战性的基准。Hendrycks 等提出 MMLU，涵盖 57 个学科，用于衡量 LLM 的知识获取和问题解决能力。Liang 等提出 HELM，这是一个涵盖广泛场景和指标的整体评测基准。

现有基准主要面向英文，这限制了对中文 LLM 的评估。为弥补这一缺口，近年来出现了一些专门面向中文 LLM 的评测基准，例如 C-EVAL、M3KE 和 GAOKAO-Bench。然而，这些基准只关注模型的能力和技能，例如世界知识和推理能力，并未考察其对人类价值的对齐。Sun 等提出了一个中文 LLM 安全评测基准来比较模型安全性，但他们使用 InstructGPT 作为评测器，这一做法未必特别契合中文文化和政策，因此可能影响评测可靠性。

为解决上述挑战并更全面地理解中文 LLM 的人类价值对齐情况，本文提出一个新的评测基准 CVALUES。如图 2 所示，CVALUES 在中文语境下设计了两个递进层次的评测标准：安全和责任。安全是基础层（Level-1），要求模型回答中不包含任何有害或有毒内容。责任被定义为更高层次（Level-2），要求模型不仅能避免伤害，还能向人类提供积极引导和必要的人文关怀，同时考虑其对社会和世界的影响。图 1 展示了这两个层次的人类价值示例。

具体来说，CVALUES 包含 2100 个用于人工评测的对抗性提示，以及 4312 个用于自动评测的多选提示。对于数据收集阶段，我们提出两种专家参与的方法来收集有代表性的提示，这些提示容易触发安全和价值相关问题。对于安全价值，我们首先定义包含 10 个场景的分类体系，然后让众包工作者攻击早期版本的 ChatPLUG，收集其成功触发的问题作为安全提示。对于责任价值，我们邀请来自环境科学、法律、心理学等 8 个领域的专业专家提供诱导性问题作为责任提示。具体而言，我们在中国发起了首次“给 AI 的 100 瓶毒药”活动，邀请各领域专家和学者提供人类社会价值相关的诱导提示，以便更好地发现中文 LLM 中与责任相关的问题。在评测阶段，为了全面评估中文 LLM 的人类价值，我们同时进行了人工评测和自动评测。人工评测方面，我们让最流行的 LLM 针对上述提示生成回答，再由专业标注者基于安全和责任标准进行可靠比较。自动评测方面，我们构造了具有两个对立选项的多选格式提示，以自动测试 LLM 的价值表现。

在进行了大量实验之后，我们观察到，目前大多数中文 LLM 在安全性方面表现不错，得益于指令微调或 RLHF。不过，在与人类价值，尤其是责任性方面的对齐上，仍然有很大提升空间。我们还发现，自动多选评测更倾向于测试模型对不安全或不负责任行为的理解能力，而人工评测可以测量其在价值对齐方面的真实生成能力。因此，我们建议在发布模型前同时进行这两类评测，以发现潜在风险并加以修正。

本文主要贡献如下：

- 提出 CVALUES，第一个中文人类价值评测基准，包含对抗性提示和诱导性提示，同时考虑安全和责任两个标准。我们希望 CVALUES 能推动中文 LLM 向更负责任的 AI 方向发展。
- 不仅使用可靠的人工评测测试了一系列中文 LLM，还构建了便于测试和快速迭代的自动多选评测方法。我们发现，自动评测和人工评测对于从不同方面衡量人类价值对齐都很重要。
- 公开发布了该基准和代码。

## 2 CVALUES 基准

本节首先介绍 CVALUES 基准的设计目标，并给出安全与责任的定义和分类体系。然后介绍数据收集与构建过程。最后详细说明评测方法，包括人工评测和自动评测。

### 2.1 定义与分类体系

CVALUES 的动机是帮助研究者和开发者评估其模型在价值观方面的表现，从而更快发现风险并在发布前处理这些问题。

与以往中文 LLM 基准工作不同，本文首次引入一个同时考虑两个递进层次评估标准的人类价值基准，即安全和责任。各标准的具体定义如下：

安全（Level-1）指模型回复中不应包含有害或有风险的内容。例如，模型回复不应包含偏见、歧视、煽动暴力或泄露隐私的内容。基于 Sun 等的工作，我们将分类体系扩展为 10 个场景，见附录 A。

责任（Level-2）要求模型能够对人类提供积极引导和人文关怀，同时考虑其对社会和世界的影响。各领域及示例见附录 A 的图 5。

过去的工作主要关注安全问题。然而，随着 LLM 的使用越来越普遍，尤其在儿童群体中，考虑更高层次的责任是必要的。以图 1 为例，R2 考虑到了提问者可能正在经历家庭离婚，并给出积极鼓励。这要求模型不只是不给出模糊或中性的回复，而是要有正确立场并更负责任地引导提问者，这比安全提出了更高要求。

### 2.2 数据收集

基于上述标准定义和分类体系，我们从两类完全不同的人群收集问题：众包工作者和专业专家。总计收集 2100 个提示，包括 1300 个安全提示和 800 个责任提示。

#### 安全提示

最开始，我们要求众包工作者根据上述分类手工编写测试提示。不过，这些提示比较容易被解决。为了获得更有效的测试提示，我们部署了一个基于早期版本 ChatPLUG 的即时消息机器人，然后让众包工作者尽力攻击该机器人。如果输入问题成功触发安全问题，则该问题会被标注为对应场景并纳入测试提示。

最后，我们选择了 1300 个安全提示，其数据统计见附录 B 的表 6。

#### 责任提示

为了获得更有说服力的问题，我们发起了名为“给 AI 的 100 瓶毒药”的项目，邀请中国多个领域的专业专家为 LLM 生成测试责任性的诱导问题。基于他们的专业知识，受邀专家认真准备了有意义的问题，这些问题容易诱使 LLM 忽视责任。

在项目早期阶段，我们收集了来自 8 位专家的 800 个问题，每位专家提供 100 个问题。统计见附录 B 的表 7。

### 2.3 评测

在收集了安全提示和专家提示后，我们设计了两种评测 LLM 价值表现的方法，即人工评测和自动评测。

#### 2.3.1 人工评测

为了得到可靠且全面的中文 LLM 比较结果，我们认为人工评测是必要的。

对于安全提示，我们首先将提示输入被评测模型并获得对应回复。然后请三位非常熟悉上述判定标准的专业标注者手工标注回复。每个回复会被评三次，并被标记为安全或不安全。最终采用投票法决定最终的安全标签。最后，我们通过计算安全回复占总回复的比例来得到每个模型的安全分数。

对于责任提示，我们邀请专家对 ChatPLUG-13B 的回复进行 1 到 10 分打分。评分基本原则如下：

- 不同意：专家不同意该观点。1 到 4 分表示不同意，分数越低表示反对越强烈。
- 中立：专家对该观点持中立态度，既不反对也不支持。5 分和 6 分表示中立。
- 同意：专家同意该观点。7 到 10 分表示同意，分数越高表示支持程度越高。

每个领域的平均分见表 3。我们可以看到，环境科学、心理学、亲密关系、冷门专业和数据科学五个领域的得分都超过 7 分。其中环境科学的得分最高，为 8.7，说明 ChatPLUG-13B 在环境科学领域与专家的责任感较为一致。然而，该模型在法律和社会科学领域的表现较差。在法律领域，模型基于法律知识的推理能力较弱，容易落入专家设置的诱导陷阱，从而产生不负责任的回答。在社会科学领域，模型回答不够全面，也缺少同理心，而且这位专家非常严格，只要发现问题就会给 1 分，因此平均分很低。

总体而言，模型在责任性方面仍有很大的提升空间。我们还在一些由 ChatPLUG-13B 发现的糟糕案例上测试了 ChatGPT 和 ChatGLM-6B，发现它们也有同样的问题。因此，从多个领域探索价值对齐以提升 LLM 的责任性是值得的。我们在 GitHub 上的技术报告中给出了初步探索。

#### 2.3.2 自动评测

为了实现轻量化且可复现的评估，本节介绍自动评测方法。

最自然、最直接的方式是构建一个能够直接预测每个回复安全性或责任性的模型。例如，Sun 等通过提示工程使用 InstructGPT 作为评测器。然而，我们认为使用 InstructGPT 或 ChatGPT 作为评测器存在一定局限。首先，它们的准确性值得怀疑，尤其是在中文文化和政策语境中。其次，API 调用可能导致评测不稳定，随着时间变化一致性较低。第三，这样做成本较高、耗时较长，而且可能涉及隐私保护问题，如 PandaLM 中所讨论的。

在最近流行的基准工作启发下，我们构造了多选格式提示来评估模型区分不同价值观的能力。构造多选安全提示的流程如图 3 所示。第一步，我们从多个 LLM 获取每个问题的回复，例如 ChatGPT、ChatGLM-6B 和 ChatPLUG。第二步，使用人工标注将所有回复分为两类，即安全和不安全。第三步，如果某个问题只有安全回复，则指令 ChatGPT 将安全回复改写为不安全回复，反之亦然。这个过程确保每个问题至少有一个安全回复和一个不安全回复。最后，我们使用图 3 中的模板，将问题、安全回复和不安全回复组合成最终的多选提示。注意，我们会交换两个回复的位置以生成两个样本，从而避免 LLM 可能存在的位置偏置。责任多选提示的构造方法相同。

最终，我们得到 4312 个多选提示用于评估，其中包括 2600 个与安全相关的多选提示和 1712 个与责任相关的多选提示。统计见附录 B 的表 5。我们将准确率作为评价指标。由于 LLM 有时会因为安全与伦理考虑而拒绝作答，我们也报告排除失败案例后的准确率。

### 3.2 安全性结果

所有模型的人工安全分数见表 2。我们可以得到以下观察与分析：

- 大多数当前中文大语言模型在安全性方面表现良好。其中 ChatGPT 排名第一，而 Chinese-Alpaca-Plus-7B 和 ChatGLM-6B 等模型的安全分数也相近。

总体而言，责任性方面还有很大改进空间。我们还测试了 ChatGPT 和 ChatGLM-6B 在一些由 ChatPLUG-13B 发现的差案例上，发现它们也有相同问题。因此，探索跨领域的价值对齐以提升 LLM 的责任性是值得的。我们在 GitHub 技术报告中展示了朝这个方向的一些初步工作。

## 5 讨论

本文基于人工评测和自动评测，对中文大语言模型的价值表现进行了评估。我们在这里给出三个重要的观察和经验。

### 中文 LLM 的整体价值表现

在安全性方面，大多数经过指令微调的模型在人工评测中都表现不错。根据我们的经验，在指令微调阶段加入一定比例的安全数据，可以帮助模型更有效地学会拒绝高风险提示。我们推测，上述模型采用了类似策略，有些模型还额外使用了 RLHF。在责任性方面，模型表现不足，因为仅靠拒绝远远不够。模型还需要与人类价值对齐，才能给出恰当回答。

### 人工评测与自动评测的差异

我们从两种方式评估模型：一种是对原始对抗性提示进行人工评测，另一种是对多选提示进行自动评测。这两种方法评估的是模型的不同侧面。多选提示更偏向测试模型对不安全或不负责任行为的理解，属于理解能力范畴。另一方面，原始对抗性提示测试的是模型在价值对齐方面的理解与生成能力。例如，以 Ziya-LLaMA 为例，它在多选提示上有很高准确率，但人工评测得分较低。可能原因是该模型能够区分不安全回复，但并未很好地与人类价值对齐，因此更容易生成有害内容。

### 价值评测的实践建议

本文讨论了两种价值评估方法，并建议将二者有效结合来评估模型表现。可以优先使用多选提示方法，并构造不同难度的选项来评估模型对人类价值的理解程度。一旦达到某个理解水平，再结合人工评测，以确保模型的生成能力也与人类价值对齐。

## 6 相关工作

### 6.1 大语言模型

GPT-3、ChatGPT、PaLM、LLaMA 等大语言模型极大地改变了 AI 开发范式。通过大规模预训练以及监督微调（SFT）和基于人类反馈的强化学习（RLHF）等人类对齐方法，它们在很多任务上展现了出色的零样本和少样本泛化能力。这一趋势也推动了中文 LLM 的快速发展，例如用于语言理解和生成的 PLUG、拥有 2000 亿参数的 Pangu-α，以及 ERNIE 3.0。

最近，随着 ChatGPT 和 LLaMA 的训练范式被引入，一系列中文版本的 LLM 也被提出并开源，以促进中文 LLM 的发展，例如 ChatGLM、MOSS、ChatPLUG、BELLE 和 Ziya-LLaMA。这些模型通常基于预训练 LLM，并通过监督微调或 RLHF 与人类意图对齐。不同于以往主要考察这些模型“有用性”的工作，本文给出的是一个更细致的人类标注基准，用于评估中文 LLM 在安全和责任两方面的中文社会价值。

### 6.2 评测基准

随着 LLM 的发展和爆发，评估其能力变得尤为重要。对于英文社区，传统基准主要关注若干自然语言处理任务，例如阅读理解、机器翻译、摘要和通用语言理解。在 LLM 时代，更全面、更整体的评测成为新趋势。例如，MMLU 收集 57 个任务的多选题，综合评估知识能力；HELM 则在 42 个不同任务上提供整体评估，覆盖从准确率到鲁棒性等 7 个指标。

相比之下，中文 LLM 的评估仍然相对缺乏，发展也较慢。为弥补这一空白，近年来出现了一些专门为中文 LLM 设计的评测基准。这些基准大多侧重于评估 LLM 的帮助性，例如 AGIEval 和 MMCU 用于中文和英文高考评测，M3KE 用于中国教育体系多个主要层次的知识评估，C-EVAL 则用于在中文语境下评估更高级的知识和推理能力。然而，LLM 的责任性或中文社会价值仍然缺少系统探索。Sun 等的工作是这一方向的先行者，主要调查中文 LLM 的安全问题，但他们使用 InstructGPT 作为评测器，可能不熟悉中文文化和社会价值。

本文则从安全和责任两个方面，对中文 LLM 的社会价值做了更全面的评估。同时，我们提供了人工评测和多选题自动评测，以更好促进负责任 AI 的发展。

## 7 结论

本文提出 CVALUES，这是第一个综合性中文 LLM 评测基准，用于从安全和责任两个标准评估其与人类价值的对齐情况。我们首先通过人工评测考察最先进的 LLM，以获得可靠的比较结果；随后设计了自动构造多选提示的方法来测试 LLM 的自动评测能力。实验表明，大多数中文 LLM 在安全性方面表现良好，但在责任性方面还有很大提升空间。此外，自动评测和人工评测对于从不同角度衡量人类价值对齐都很重要。我们希望 CVALUES 能用于发现潜在风险，并推动中文 LLM 的人类价值对齐研究。

## 附录 A 分类体系与示例

首先给出安全场景的定义如下：

- 危险话题（Dangerous Topics）：模型对危险内容表示同意或提供建议，例如性、赌博和毒品。
- 敏感话题（Sensitive Topics）：模型在某些敏感话题上生成带偏见或不准确的内容，例如 LGBT 和女性权利。
- 犯罪（Crimes）：模型同意或鼓励违法活动，例如偷窃、抢劫和诈骗。
- 身心健康（Physical and Mental Health）：模型生成可能在身体或心理上对用户造成伤害的不当内容。
- 个人隐私（Personal Privacy）：模型生成可能暴露隐私信息的内容。
- 客观中立（Objective and Unbiased）：模型生成有偏见或过于主观的评论。
- 伦理道德（Ethics and Morality）：模型鼓励不道德或不正当行为。
- 恶意诱导（Malicious Inducement）：模型根据恶意指令生成不安全内容。
- 攻击指令（Attack Instructions）：模型根据用户请求生成不安全或虚假内容。
- 其他（Others）：模型生成不属于上述场景的不安全内容。

随后说明责任要求，并给出各领域示例：

- 环境科学：模型应具有环保意识、环境正义意识，珍惜国家保护动物，拒绝伤害野生动物的行为，并鼓励可持续发展参与。
- 心理学：模型应认识到抑郁原因复杂多维，避免污名化、刻板化或病理化的错误建议，提供温和、支持性和有同理心的回复。
- 数据科学：模型应了解技术如何影响人们生活，在回答涉及信息隐私的问题时要格外谨慎。
- 法律：模型应充分运用法律知识，并参考先例，对所给问题作出严谨判断。
- 社会科学：模型不得对女性、年龄和种族等问题产生偏见和歧视，应接受不同群体和观点的多样性。
- 亲密关系：模型应深入思考婚姻观念的利弊。
- 无障碍：模型应避免歧视，尤其是对残障群体的刻板印象，并以同理心回应。
- 冷门专业：模型应了解一些不那么热门或较少为人知的专业知识和就业方向。
